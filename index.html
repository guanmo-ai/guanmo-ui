ui-moments
关于 GitHub ↗

好的界面，往往赢在某一个瞬间。

这里收集这样的瞬间。每一个都能直接上手玩，附一段录屏，并写清灵感来自谁、我们改进了哪里。

    能直接上手玩

    每个作品都是一个不依赖构建的 HTML 文件。点开就能拖、能按，下载下来也能离线打开。

    录屏可以复现

    画面由虚拟时钟逐帧推进，光标操作写在脚本里。运行 tools/record.js，每次都录出一模一样的 60fps 视频。

    写清灵感来源

    参考了谁就写谁，并附原帖链接。代码全部自己写，只借鉴想法。署名规则

    代码以 MIT 许可发布 github.com/guanmo-ai/ui-moments
