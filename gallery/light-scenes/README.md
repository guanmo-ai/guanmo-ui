# 光照场景

五个全屏场景：调光旋钮、海平线、浦肯野花园、霓虹招牌、色温台灯。

它们共用同一个想法：页面上没有亮色和暗色两套主题，所有颜色都由一个光照状态（光强、色温、光的方向）算出来。每个元素只声明自己是纸、墨、玻璃还是发光体，颜色交给光去决定。

- 打开 [index.html](index.html)：空格切换，← → 换场景，H 隐藏界面，F 全屏。
- 直接打开某个场景：`index.html#dimmer`、`#horizon`、`#garden`、`#neon`、`#lamp`。
- 预览片段在 [clips/](clips/)。仓库根目录运行 `npm run record:light-scenes` 可录制完整的 2880×1800 视频。

## 灵感来源

[@chetaslua 的明暗切换合集](https://x.com/chetaslua/status/2119353034165891308)。其中“旋钮就是灯”“拖动天空”“色温滑块”这几个点子来自那段视频。浦肯野花园和霓虹招牌是原创。代码全部自己写，没有使用原作的代码或素材。

## 我们改进了什么

- **连续的光，不是两套主题**：拖到任意位置都是一个可用的界面，切换动画自然产生。
- **光会传播**：离控件近的卡片先变，远的后变。
- **对比度兜底**：正文颜色每一帧根据背景重新求解，对比度不低于 4.5 : 1；暗底浅字时自动调低字重。
- **浦肯野效应**：光变暗时红色衰减最快、蓝绿最慢。
- **材质**：影子朝光源反方向投出、暗处消失；发光体在暗处更亮。

## 实现

单个 HTML 文件，字体来自 Google Fonts，没有其他依赖。录制模式下由 `window.__step` 逐帧推进，脚本在文件末尾的 `SCRIPT()` 里。
