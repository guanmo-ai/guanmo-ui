# 参考与署名

做界面难免参考别人。我们不回避参考，只要求说清楚。

## 每个作品都要写

在作品目录的 README 里写明：

- **灵感来源**：原作者，以及原帖、原仓库或原网页的链接。
- **借鉴了什么**：比如交互方式、构图、某个动效。
- **我们改进了什么**：和原作相比，哪里做得不同、为什么更好。
- **第三方代码和资源**：名称、链接、许可证。

画廊里的作品卡片同样显示“灵感来自 @某某”。

## 什么能直接用

- **有开源许可证的代码和资源**（如 MIT、Apache 2.0、OFL）：可以使用，按许可证要求保留版权声明和许可证文本；Apache 2.0 还要注明修改过的文件。
- **没有许可证的作品**（推文、截图、视频、网页）：只借鉴想法，代码和素材全部自己写、自己画。
- **以下内容不放进仓库**：
  - 苹果的 SF 字体、SF Symbols 和 HIG 原文（不是开源的）。
  - Shopify Polaris 的代码（许可证带有使用限制）。
  - Salesforce 的图标和图片（CC BY-ND，不允许修改）。
  - 任何公司的商标和 Logo。也不暗示得到了对方认可。

## 太像就不发

如果作品和原作几乎一样，只是换了实现方式，就不发布，或者先征得原作者同意。
